## La idea: dividir a la mitad

Imagina que juegas "adivina el número". Tu amigo piensa un número del 1 al 100 y tú solo puedes preguntar "¿es mayor o menor?". La estrategia más inteligente: siempre preguntar por **la mitad**.

- "¿Es 50?" → "Mayor"
- "¿Es 75?" → "Menor"
- "¿Es 62?" → "Mayor"
- "¿Es 68?" → "¡Sí!"

En solo 7 preguntas puedes encontrar cualquier número entre 1 y 100. Con búsqueda lineal (probar uno por uno), podrías necesitar hasta 100.

**Búsqueda binaria** funciona igual: en un arreglo **ordenado**, compara con el elemento del medio. Si es menor, busca en la mitad izquierda. Si es mayor, en la derecha. En cada paso, **eliminamos la mitad** del espacio de búsqueda.

## Requisito fundamental

<Callout type="warning">
  Para buscar por valor en un vector, ordénalo según el mismo criterio que
  usarás al comparar. Más generalmente, necesitas una condición monótona que
  cambie una sola vez entre falso y verdadero. No es obligatorio almacenar un
  arreglo: también puedes buscar una respuesta numérica si demuestras esa
  monotonía.
</Callout>

## Invariante y fronteras

Una forma de buscar la primera posición cuyo valor sea al menos el objetivo mantiene un intervalo semiabierto. Todas las posiciones antes de `izquierda` son demasiado pequeñas y todas desde `derecha` cumplen, o están después del arreglo. Al terminar, ambas fronteras coinciden en el punto de cambio.

```cpp test
#include <iostream>
#include <vector>
using namespace std;

int encontrar(const vector<int>& valores, int objetivo) {
        int izquierda = 0, derecha = static_cast<int>(valores.size());
        while (izquierda < derecha) {
                int medio = izquierda + (derecha - izquierda) / 2;
                if (valores[medio] < objetivo) izquierda = medio + 1;
                else derecha = medio;
        }
        if (izquierda == static_cast<int>(valores.size()) || valores[izquierda] != objetivo) return -1;
        return izquierda;
}

int main() {
        cout << encontrar({1, 3, 3, 8}, 3) << '\n';
        cout << encontrar({1, 3, 3, 8}, 4) << '\n';
        cout << encontrar({}, 3) << '\n';
}
```

Salida:

```text output
1
-1
-1
```

El intervalo se reduce estrictamente: nunca dejes `izquierda = medio` cuando el redondeo podría repetir el mismo punto. Esta versión devuelve la primera copia del valor; la versión de igualdad inmediata de abajo puede devolver cualquiera de las copias. El coste es $O(\log(n+1))$ y espacio adicional constante.

**Comprueba:** todos iguales, valor menor que todos, mayor que todos, un elemento y arreglo vacío. Para búsqueda sobre una respuesta, agrega también los casos «ninguna respuesta es viable» y «todas son viables».

## Implementación básica

```cpp
int busquedaBinaria(vector<int> &v, int objetivo) {
    int lo = 0, hi = static_cast<int>(v.size()) - 1;

    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;  // Punto medio

        if (v[mid] == objetivo) {
            return mid;      // ¡Encontrado!
        } else if (v[mid] < objetivo) {
            lo = mid + 1;    // Buscar en la mitad derecha
        } else {
            hi = mid - 1;    // Buscar en la mitad izquierda
        }
    }

    return -1;  // No encontrado
}
```

**¿Por qué `lo + (hi - lo) / 2` en lugar de `(lo + hi) / 2`?** Para evitar overflow. Si `lo` y `hi` son muy grandes, su suma podría superar el rango de `int`.

### Paso a paso

Buscar `7` en `[1, 3, 5, 7, 9, 11, 13]`:

| Paso | lo  | hi  | mid | v[mid] | Acción       |
| ---- | --- | --- | --- | ------ | ------------ |
| 1    | 0   | 6   | 3   | 7      | ¡Encontrado! |

Buscar `6`:

| Paso | lo  | hi  | mid | v[mid] | Acción                  |
| ---- | --- | --- | --- | ------ | ----------------------- |
| 1    | 0   | 6   | 3   | 7      | 6 &lt; 7, hi = 2        |
| 2    | 0   | 2   | 1   | 3      | 6 > 3, lo = 2           |
| 3    | 2   | 2   | 2   | 5      | 6 > 5, lo = 3           |
| 4    | 3   | 2   | -   | -      | lo > hi → No encontrado |

## Complejidad

- **Tiempo:** $O(\log n)$
- **Espacio:** $O(1)$

| $n$           | Pasos máximos |
| ------------- | ------------- |
| 100           | 7             |
| 1,000         | 10            |
| 1,000,000     | 20            |
| 1,000,000,000 | 30            |

¡Con solo 30 comparaciones puedes buscar entre MIL MILLONES de elementos!

## Funciones de búsqueda binaria en C++

C++ ya tiene búsqueda binaria incorporada:

```cpp
vector<int> v = {1, 3, 5, 7, 9, 11};

// ¿Existe el elemento?
bool existe = binary_search(v.begin(), v.end(), 7);  // true

// Posición del primer elemento >= x
auto it = lower_bound(v.begin(), v.end(), 6);  // Apunta a 7 (índice 3)
int pos = it - v.begin();  // 3

// Posición del primer elemento > x
auto it2 = upper_bound(v.begin(), v.end(), 7);  // Apunta a 9 (índice 4)
```

## Búsqueda binaria en la respuesta

Esta es una técnica **poderosísima** en competencias. En lugar de buscar un elemento en un arreglo, buscas **la respuesta óptima a un problema**.

**Patrón:** Si puedes formular la pregunta "¿es posible lograr una respuesta de X?", y la respuesta cambia de "No" a "Sí" (o viceversa) en algún punto, puedes hacer búsqueda binaria.

### Ejemplo: cortar troncos

**Problema:** Tienes N troncos de diferentes longitudes. Necesitas obtener K troncos de longitud L cortándolos. ¿Cuál es la L máxima posible?

```cpp
bool esPosible(vector<int> &troncos, int longitud, int k) {
    long long total = 0;
    for (int t : troncos) {
        total += t / longitud;
    }
    return total >= k;
}

int maxLongitud(vector<int> &troncos, int k) {
    if (troncos.empty()) return 0;
    int lo = 1, hi = *max_element(troncos.begin(), troncos.end());
    int respuesta = 0;

    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (esPosible(troncos, mid, k)) {
            respuesta = mid;
            lo = mid + 1;
        } else {
            hi = mid - 1;
        }
    }

    return respuesta;
}
```

Este ejemplo de troncos supone longitudes no negativas y una cantidad pedida `k` positiva. Probar longitudes desde 1 evita dividir entre cero. Cada prueba recorre los troncos, así que el tiempo total es $O(n\log L)$, donde $L$ es la longitud máxima; no es solo $O(\log L)$.

## Ejercicio de práctica

Dado un arreglo ordenado con posibles duplicados, encuentra cuántas veces aparece un número X.

**Entrada:**

```
8 3
1 2 3 3 3 4 5 6
```

**Salida:** `3`

<details>
<summary>Ver solución</summary>

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n, x;
    cin >> n >> x;

    vector<int> v(n);
    for (int i = 0; i < n; i++) cin >> v[i];

    auto lo = lower_bound(v.begin(), v.end(), x);
    auto hi = upper_bound(v.begin(), v.end(), x);

    cout << (hi - lo) << endl;

    return 0;
}
```

`lower_bound` apunta al primer X, `upper_bound` apunta al primer elemento después del último X. La diferencia es la cantidad de X's.

</details>
