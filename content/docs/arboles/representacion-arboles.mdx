## El punto de partida: dos lugares para hijos

Un árbol binario enraizado tiene, para cada nodo, un posible hijo izquierdo y un posible hijo derecho. Puede tener cero, uno o dos hijos. Izquierda y derecha son posiciones distintas: un nodo con solo hijo izquierdo no tiene la misma forma que uno con solo hijo derecho.

No hay una regla automática sobre sus valores. Un **árbol binario de búsqueda (BST)** añade una relación de orden; un **heap** añade otra propiedad diferente. Tampoco todo árbol binario está balanceado: puede ser una cadena de altura $n-1$.

```cpp test
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

struct Nodo { int valor, izquierdo, derecho; };

int altura(const vector<Nodo>& arbol, int actual) {
    if (actual == -1) return -1;
    return 1 + max(altura(arbol, arbol[actual].izquierdo), altura(arbol, arbol[actual].derecho));
}

int main() {
    vector<Nodo> arbol = {{8, 1, 2}, {20, -1, -1}, {3, -1, -1}};
    cout << altura(arbol, 0) << '\n';
}
```

Salida:

```text output
1
```

La raíz de valor 8 tiene hijos 20 y 3. Es un árbol binario, pero no un BST. `-1` representa un hijo ausente; se comprueba antes de acceder al vector. Medimos altura en **aristas**, de modo que una hoja tiene altura 0. La función recorre $O(n)$ nodos y usa pila proporcional a la altura; para árboles muy profundos usa un recorrido iterativo.

Un árbol **lleno** tiene cero o dos hijos por nodo; uno **completo** llena niveles de izquierda a derecha salvo quizá el último; uno **perfecto** tiene todos los niveles completos. No son sinónimos.

**Practica:** agrega un hijo al nodo 20. La altura pasa a 2. Si asignas a un hijo el índice de un ancestro, creas un ciclo y la estructura deja de ser un árbol: la función anterior ya no tiene garantizada la terminación.

## ¿Qué es un árbol?

Un **árbol** es un grafo conectado sin ciclos. Piénsalo como un árbol genealógico: hay un **ancestro** (raíz), sus **hijos**, los hijos de sus hijos (nietos), etc.

**Propiedades clave:**

- Un árbol con N nodos tiene exactamente **N-1 aristas**.
- Hay exactamente **un camino** entre cualquier par de nodos.
- Si quitas una arista, se desconecta. Si agregas una, creas un ciclo.

## Terminología

```
        1        ← Raíz
       / \
      2   3      ← Hijos de 1
     /|    \
    4 5     6    ← Hojas: 4, 5, 6
```

| Término         | Significado                                    |
| --------------- | ---------------------------------------------- |
| **Raíz**        | Nodo superior (1)                              |
| **Padre**       | Nodo directamente arriba (padre de 4 es 2)     |
| **Hijo**        | Nodo directamente abajo (hijos de 2 son 4 y 5) |
| **Hoja**        | Nodo sin hijos (4, 5, 6)                       |
| **Profundidad** | Distancia a la raíz (profundidad de 4 es 2)    |
| **Altura**      | Distancia máxima a una hoja                    |
| **Subárbol**    | Un nodo y todos sus descendientes              |

## Representación 1: Lista de adyacencia

La forma más común en competencias:

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int MAXN = 100005;
vector<int> hijos[MAXN];
int padre[MAXN];

int main() {
    int n;
    cin >> n;

    // Leer n-1 aristas
    for (int i = 0; i < n - 1; i++) {
        int u, v;
        cin >> u >> v;
        hijos[u].push_back(v);
        hijos[v].push_back(u);
    }

    return 0;
}
```

Si no se especifica la raíz, el árbol se da como un grafo no dirigido y tú eliges la raíz (generalmente el nodo 1).

## Representación 2: Padre de cada nodo

A veces el problema te da el padre de cada nodo directamente:

```cpp
int padre[MAXN];

int main() {
    int n;
    cin >> n;

    // padre[i] = padre del nodo i
    for (int i = 2; i <= n; i++) {
        cin >> padre[i];
    }
    // padre[1] no existe (la raíz no tiene padre)
}
```

## Calcular propiedades con DFS

### Profundidad de cada nodo

```cpp
int profundidad[MAXN];

void dfs(int nodo, int padre, int prof) {
    profundidad[nodo] = prof;

    for (int hijo : hijos[nodo]) {
        if (hijo != padre) {
            dfs(hijo, nodo, prof + 1);
        }
    }
}

// Llamar: dfs(1, 0, 0);
```

### Tamaño de cada subárbol

```cpp
int tam[MAXN];

void calcTam(int nodo, int padre) {
    tam[nodo] = 1;
    for (int hijo : hijos[nodo]) {
        if (hijo != padre) {
            calcTam(hijo, nodo);
            tam[nodo] += tam[hijo];
        }
    }
}
```

### Altura del árbol

```cpp
int altura(int nodo, int padre) {
    int maxH = 0;
    for (int hijo : hijos[nodo]) {
        if (hijo != padre) {
            maxH = max(maxH, 1 + altura(hijo, nodo));
        }
    }
    return maxH;
}
```

## Diámetro del árbol

El **diámetro** es el camino más largo entre dos nodos del árbol. Se puede encontrar con dos BFS:

```cpp
pair<int,int> bfsMasLejano(int inicio, int n) {
    vector<int> dist(n + 1, -1);
    queue<int> q;
    q.push(inicio);
    dist[inicio] = 0;

    int masLejano = inicio;
    while (!q.empty()) {
        int nodo = q.front(); q.pop();
        for (int v : hijos[nodo]) {
            if (dist[v] == -1) {
                dist[v] = dist[nodo] + 1;
                q.push(v);
                if (dist[v] > dist[masLejano]) masLejano = v;
            }
        }
    }

    return {masLejano, dist[masLejano]};
}

int diametro(int n) {
    auto [a, _] = bfsMasLejano(1, n);
    auto [b, d] = bfsMasLejano(a, n);
    return d;
}
```

**Idea:** Desde cualquier nodo, el más lejano es un extremo del diámetro. Desde ese extremo, el más lejano es el otro extremo.
