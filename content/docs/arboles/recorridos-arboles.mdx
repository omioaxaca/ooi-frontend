## Los tres recorridos fundamentales

**Objetivo:** distinguir el momento de procesar un nodo del momento de entrar a su llamada. Los tres recorridos visitan los mismos nodos; solo cambia cuándo se emite el valor respecto a los hijos. Necesitas árboles binarios y recursión.

## Comparación ejecutable

Una misma función puede registrar los tres momentos. El nodo actual se agrega al preorden antes del hijo izquierdo, al inorden entre los dos hijos y al postorden después del derecho.

```cpp test
#include <iostream>
#include <vector>
using namespace std;

struct Nodo { int valor, izquierdo, derecho; };

void recorrer(int actual, const vector<Nodo>& arbol, vector<int>& preorden, vector<int>& inorden, vector<int>& postorden) {
    if (actual == -1) return;
    preorden.push_back(arbol[actual].valor);
    recorrer(arbol[actual].izquierdo, arbol, preorden, inorden, postorden);
    inorden.push_back(arbol[actual].valor);
    recorrer(arbol[actual].derecho, arbol, preorden, inorden, postorden);
    postorden.push_back(arbol[actual].valor);
}

void imprimir(const vector<int>& valores) {
    for (int indice = 0; indice < static_cast<int>(valores.size()); indice++) {
        if (indice > 0) cout << ' ';
        cout << valores[indice];
    }
    cout << '\n';
}

int main() {
    vector<Nodo> arbol = {{1, 1, 2}, {2, 3, 4}, {3, -1, 5}, {4, -1, -1}, {5, -1, -1}, {6, -1, -1}};
    vector<int> preorden, inorden, postorden;
    recorrer(0, arbol, preorden, inorden, postorden);
    imprimir(preorden);
    imprimir(inorden);
    imprimir(postorden);
}
```

Salida:

```text output
1 2 4 5 3 6
4 2 5 1 3 6
4 5 2 6 3 1
```

Cada recorrido cuesta $O(n)$ y la pila usa $O(altura)$. Guardar las tres salidas añade $O(n)$ memoria. El inorden de este ejemplo **no** está ordenado: esa propiedad requiere un BST, no cualquier árbol binario.

**Autocomprobación:** un árbol vacío no emite valores y una hoja aparece igual en los tres recorridos. Preorden e inorden permiten reconstrucción única si las claves son distintas; con repetidos o solo preorden y postorden puede haber ambigüedad.

En un árbol binario, cada nodo tiene a lo más dos hijos: **izquierdo** y **derecho**. Hay tres formas clásicas de visitarlos:

```
        1
       / \
      2   3
     / \   \
    4   5   6
```

| Recorrido     | Orden                      | Resultado        |
| ------------- | -------------------------- | ---------------- |
| **Preorden**  | Nodo → Izquierda → Derecha | 1, 2, 4, 5, 3, 6 |
| **Inorden**   | Izquierda → Nodo → Derecha | 4, 2, 5, 1, 3, 6 |
| **Postorden** | Izquierda → Derecha → Nodo | 4, 5, 2, 6, 3, 1 |

**Truco para recordar:** El nombre indica cuándo visitas la **raíz**: **pre** (antes), **in** (en medio), **post** (después).

## Implementación

### Estructura del árbol binario

```cpp
struct Nodo {
    int valor;
    int izq, der;  // -1 si no tiene hijo
};

Nodo arbol[100005];
```

### Preorden (NID)

```cpp
void preorden(int nodo) {
    if (nodo == -1) return;

    cout << arbol[nodo].valor << " ";  // Nodo
    preorden(arbol[nodo].izq);          // Izquierda
    preorden(arbol[nodo].der);          // Derecha
}
```

### Inorden (IND)

```cpp
void inorden(int nodo) {
    if (nodo == -1) return;

    inorden(arbol[nodo].izq);           // Izquierda
    cout << arbol[nodo].valor << " ";  // Nodo
    inorden(arbol[nodo].der);           // Derecha
}
```

### Postorden (IDN)

```cpp
void postorden(int nodo) {
    if (nodo == -1) return;

    postorden(arbol[nodo].izq);         // Izquierda
    postorden(arbol[nodo].der);         // Derecha
    cout << arbol[nodo].valor << " ";  // Nodo
}
```

## Recorrido por niveles (BFS)

Visitar nivel por nivel, de izquierda a derecha:

```cpp
void porNiveles(int raiz) {
    if (raiz == -1) return;
    queue<int> q;
    q.push(raiz);

    while (!q.empty()) {
        int nodo = q.front();
        q.pop();

        cout << arbol[nodo].valor << " ";

        if (arbol[nodo].izq != -1) q.push(arbol[nodo].izq);
        if (arbol[nodo].der != -1) q.push(arbol[nodo].der);
    }
}
// Resultado para el ejemplo: 1 2 3 4 5 6
```

## Recorridos en árboles generales (no binarios)

En competencias, los árboles generalmente no son binarios. Usamos DFS:

```cpp
vector<int> adj[100005];

// Preorden (euler tour - tiempo de entrada)
int tin[100005], tout[100005], timer = 0;

void dfs(int nodo, int padre) {
    tin[nodo] = timer++;

    // Procesar nodo aquí (preorden)

    for (int hijo : adj[nodo]) {
        if (hijo != padre) {
            dfs(hijo, nodo);
        }
    }

    tout[nodo] = timer++;
    // Procesar nodo aquí (postorden)
}
```

## Euler Tour

El ejemplo siguiente registra entrada y salida una vez por vértice, para un total de $2n$ eventos. Sirve para probar relaciones de ancestro. Para sumar subárboles suele usarse un aplanamiento de $n$ entradas; para LCA por RMQ, un recorrido de $2n-1$ entradas que registra cada regreso de un hijo. Esas variantes no son intercambiables.

Técnica fundamental: asignar a cada nodo un **tiempo de entrada** y **salida**. Esto convierte el árbol en un arreglo lineal.

```cpp
int tin[100005], tout[100005], timer = 0;
int eulerTour[200005];  // El recorrido completo

void euler(int nodo, int padre) {
    tin[nodo] = timer;
    eulerTour[timer++] = nodo;

    for (int hijo : adj[nodo]) {
        if (hijo != padre) {
            euler(hijo, nodo);
        }
    }

    tout[nodo] = timer;
    eulerTour[timer++] = nodo;
}
```

**Propiedad clave:** El nodo `u` es ancestro de `v` si y solo si `tin[u] ≤ tin[v]` y `tout[u] ≥ tout[v]`.

## Reconstruir árbol a partir de recorridos

**Problema clásico:** Dados el preorden y el inorden, reconstruir el árbol.

```cpp
int preorden[] = {1, 2, 4, 5, 3, 6};
int inorden[]  = {4, 2, 5, 1, 3, 6};

int construir(int preL, int preR, int inL, int inR) {
    if (preL > preR) return -1;

    int raiz = preorden[preL];

    // Encontrar la raíz en inorden
    int pos = inL;
    while (inorden[pos] != raiz) pos++;

    int tamIzq = pos - inL;

    arbol[raiz].izq = construir(preL + 1, preL + tamIzq, inL, pos - 1);
    arbol[raiz].der = construir(preL + tamIzq + 1, preR, pos + 1, inR);

    return raiz;
}
```

## Ejercicio de práctica

Dado un árbol binario representado con padre y dirección (I=izquierdo, D=derecho), imprime los recorridos preorden, inorden y postorden.

```cpp
#include <iostream>
using namespace std;

struct Nodo {
    int izq = -1, der = -1;
};

Nodo arbol[105];

void pre(int n) {
    if (n == -1) return;
    cout << n << " ";
    pre(arbol[n].izq);
    pre(arbol[n].der);
}

void in(int n) {
    if (n == -1) return;
    in(arbol[n].izq);
    cout << n << " ";
    in(arbol[n].der);
}

void post(int n) {
    if (n == -1) return;
    post(arbol[n].izq);
    post(arbol[n].der);
    cout << n << " ";
}

int main() {
    int n;
    cin >> n;

    bool esHijo[105] = {};
    for (int i = 0; i < n - 1; i++) {
        int padre, hijo;
        char dir;
        cin >> padre >> hijo >> dir;
        if (dir == 'I') arbol[padre].izq = hijo;
        else arbol[padre].der = hijo;
        esHijo[hijo] = true;
    }

    // Encontrar la raíz (nodo que no es hijo de nadie)
    int raiz = 1;
    for (int i = 1; i <= n; i++) {
        if (!esHijo[i]) { raiz = i; break; }
    }

    cout << "Preorden: "; pre(raiz); cout << endl;
    cout << "Inorden: "; in(raiz); cout << endl;
    cout << "Postorden: "; post(raiz); cout << endl;

    return 0;
}
```
