## Antes de empezar

Repasa [profundidades y padres](/blog/arboles/recorridos-bfs-dfs). El **ancestro común más bajo** de dos vértices es su ancestro compartido de mayor profundidad. Un vértice se considera ancestro de sí mismo.

Binary lifting sirve para cualquier árbol enraizado, no solamente para árboles binarios. «Binary» se refiere a descomponer distancias en potencias de dos.

## Saltos que se duplican

Define `ancestro[potencia][vertice]` como el ancestro situado $2^{potencia}$ aristas arriba. La primera fila contiene al padre. Para construir la siguiente, realiza dos saltos de la mitad de tamaño:

$$up[k][v]=up[k-1][up[k-1][v]].$$

Hacemos que el padre de la raíz sea la propia raíz, de modo que un salto por encima de ella siga siendo un índice válido.

## Resolver una consulta

1. Sube el vértice más profundo hasta igualar profundidades, descomponiendo la diferencia en potencias de dos.
2. Si los vértices coinciden, ese es el LCA.
3. Si no, prueba saltos de mayor a menor. Cuando sus ancestros a esa distancia son distintos, sube ambos: todavía están debajo del LCA.
4. Al terminar, ambos tienen el mismo padre; ese padre es la respuesta.

En el árbol con aristas `0-1`, `0-2`, `1-3`, `1-4`, el LCA de 3 y 4 es 1. El de 2 y 4 es 0. El de 1 y 4 es 1, pues uno ya era ancestro del otro.

## C++17

Entrada: árbol no vacío, raíz 0 y consultas sobre vértices indexados desde cero. Cada salida contiene LCA y distancia en número de aristas.

```cpp test
#include <algorithm>
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int lca(int primero, int segundo, const vector<int>& profundidad, const vector<vector<int>>& ancestro) {
    if (profundidad[primero] < profundidad[segundo]) swap(primero, segundo);
    int diferencia = profundidad[primero] - profundidad[segundo];
    int niveles = static_cast<int>(ancestro.size());
    for (int salto = 0; salto < niveles; salto++) {
        if ((diferencia >> salto) & 1) primero = ancestro[salto][primero];
    }
    if (primero == segundo) return primero;
    for (int salto = niveles - 1; salto >= 0; salto--) {
        if (ancestro[salto][primero] != ancestro[salto][segundo]) {
            primero = ancestro[salto][primero];
            segundo = ancestro[salto][segundo];
        }
    }
    return ancestro[0][primero];
}

int main() {
    int cantidad, consultas;
    cin >> cantidad >> consultas;
    vector<vector<int>> vecinos(cantidad);
    for (int indice = 1; indice < cantidad; indice++) {
        int origen, destino;
        cin >> origen >> destino;
        vecinos[origen].push_back(destino);
        vecinos[destino].push_back(origen);
    }
    int niveles = 1;
    while ((1LL << niveles) <= cantidad) niveles++;
    vector<vector<int>> ancestro(niveles, vector<int>(cantidad, 0));
    vector<int> profundidad(cantidad, 0);
    queue<int> pendientes;
    pendientes.push(0);
    while (!pendientes.empty()) {
        int actual = pendientes.front();
        pendientes.pop();
        for (int vecino : vecinos[actual]) {
            if (vecino == ancestro[0][actual]) continue;
            ancestro[0][vecino] = actual;
            profundidad[vecino] = profundidad[actual] + 1;
            pendientes.push(vecino);
        }
    }
    for (int salto = 1; salto < niveles; salto++) {
        for (int vertice = 0; vertice < cantidad; vertice++) {
            ancestro[salto][vertice] = ancestro[salto - 1][ancestro[salto - 1][vertice]];
        }
    }
    while (consultas--) {
        int primero, segundo;
        cin >> primero >> segundo;
        int comun = lca(primero, segundo, profundidad, ancestro);
        cout << comun << ' ' << profundidad[primero] + profundidad[segundo] - 2 * profundidad[comun] << '\n';
    }
}
```

Entrada:

```text input
5 3
0 1
0 2
1 3
1 4
3 4
2 4
4 4
```

Salida:

```text output
1 2
0 3
4 0
```

## Coste y límites

El preprocesamiento y la memoria cuestan $O(n\log n)$; una consulta cuesta $O(\log n)$. BFS evita una recursión profunda al construir padres. El código supone un árbol válido: no aplica directamente a un grafo con ciclos o a vértices de componentes distintas.

Para aristas con pesos, guarda la suma de pesos desde la raíz para calcular distancias, pero usa la **profundidad en aristas** para igualar alturas durante LCA.
