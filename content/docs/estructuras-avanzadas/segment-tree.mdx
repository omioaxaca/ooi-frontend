## ¿Qué es un Segment Tree?

**Analogía:** Imagina que eres director de una escuela con 1000 alumnos. Quieres saber rápidamente: "¿Cuál es la calificación más alta entre el alumno 50 y el 200?". Además, a veces cambias calificaciones. En vez de revisar uno por uno, organizas a los alumnos en un **árbol** donde cada nodo guarda información resumida de un rango.

Un segment tree divide recursivamente el arreglo en intervalos y combina sus resultados. En la representación habitual:

- Cada hoja representa un elemento del arreglo.
- Cada nodo interno guarda el resultado de combinar sus dos hijos (suma, mínimo, máximo, etc.).

```
Arreglo: [2, 1, 5, 3, 4, 7]

              22          ← suma total
           /      \
         8          14
        / \        / \
       3    5    7    7
      / \   |   / \   |
     2   1  5  3   4   7
```

## Implementación básica (suma)

Usamos un arreglo `tree[]` de tamaño $4n$. El nodo `v` tiene hijos `2v` y `2v+1`.

```cpp
const int MAXN = 200005;
int tree[4 * MAXN];
int arr[MAXN];
int n;

// Construir el árbol
void build(int v, int tl, int tr) {
    if (tl == tr) {
        tree[v] = arr[tl];  // Hoja
        return;
    }

    int tm = (tl + tr) / 2;
    build(2*v, tl, tm);       // Hijo izquierdo
    build(2*v+1, tm+1, tr);   // Hijo derecho
    tree[v] = tree[2*v] + tree[2*v+1];  // Combinar
}

// Consultar suma en [l, r]
int query(int v, int tl, int tr, int l, int r) {
    if (l > tr || r < tl) return 0;  // Fuera de rango
    if (l <= tl && tr <= r) return tree[v];  // Completamente dentro

    int tm = (tl + tr) / 2;
    return query(2*v, tl, tm, l, r) +
           query(2*v+1, tm+1, tr, l, r);
}

// Actualizar posición pos con valor val
void update(int v, int tl, int tr, int pos, int val) {
    if (tl == tr) {
        tree[v] = val;
        return;
    }

    int tm = (tl + tr) / 2;
    if (pos <= tm) update(2*v, tl, tm, pos, val);
    else update(2*v+1, tm+1, tr, pos, val);

    tree[v] = tree[2*v] + tree[2*v+1];  // Recalcular
}
```

### Uso

```cpp
int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> arr[i];

    build(1, 1, n);  // Construir desde la raíz

    // Consultar suma [2, 5]
    cout << query(1, 1, n, 2, 5) << endl;

    // Cambiar posición 3 a valor 10
    update(1, 1, n, 3, 10);

    return 0;
}
```

Tanto consulta como actualización son $O(\log n)$.

## Segment Tree de mínimo

Solo cambia la operación de combinación:

```cpp
void build(int v, int tl, int tr) {
    if (tl == tr) { tree[v] = arr[tl]; return; }
    int tm = (tl + tr) / 2;
    build(2*v, tl, tm);
    build(2*v+1, tm+1, tr);
    tree[v] = min(tree[2*v], tree[2*v+1]);  // min en vez de suma
}

int query(int v, int tl, int tr, int l, int r) {
    if (l > tr || r < tl) return INT_MAX;  // Neutro del min
    if (l <= tl && tr <= r) return tree[v];
    int tm = (tl + tr) / 2;
    return min(query(2*v, tl, tm, l, r),
               query(2*v+1, tm+1, tr, l, r));
}
```

## Euler tour: un subárbol es un intervalo

Registra cada vértice **una vez al entrar** en DFS y guarda `entrada[vertice]` y `salida[vertice]`, donde salida es el siguiente índice libre al terminar sus hijos. Todos sus descendientes quedan juntos en `[entrada, salida)`.

Este aplanamiento tiene $n$ elementos. No lo confundas con el recorrido de $2n-1$ elementos que repite regresos para resolver LCA. Aquí queremos que cada valor de vértice se sume una sola vez.

```cpp test
#include <iostream>
#include <vector>
using namespace std;

void aplanar(int actual, int padre, const vector<vector<int>>& vecinos, const vector<int>& valor,
             vector<int>& entrada, vector<int>& salida, vector<int>& plano) {
    entrada[actual] = static_cast<int>(plano.size());
    plano.push_back(valor[actual]);
    for (int vecino : vecinos[actual]) if (vecino != padre) aplanar(vecino, actual, vecinos, valor, entrada, salida, plano);
    salida[actual] = static_cast<int>(plano.size());
}

int main() {
    vector<vector<int>> vecinos = {{1, 2}, {0, 3, 4}, {0}, {1}, {1}};
    vector<int> valor = {1, 2, 3, 4, 5}, entrada(5), salida(5), plano;
    aplanar(0, -1, vecinos, valor, entrada, salida, plano);
    int cantidad = static_cast<int>(plano.size());
    vector<long long> arbol(2 * cantidad, 0);
    for (int indice = 0; indice < cantidad; indice++) arbol[cantidad + indice] = plano[indice];
    for (int nodo = cantidad - 1; nodo > 0; nodo--) arbol[nodo] = arbol[2 * nodo] + arbol[2 * nodo + 1];
    auto consultar = [&](int izquierda, int derecha) {
        long long suma = 0;
        for (izquierda += cantidad, derecha += cantidad; izquierda < derecha; izquierda /= 2, derecha /= 2) {
            if (izquierda % 2 == 1) suma += arbol[izquierda++];
            if (derecha % 2 == 1) suma += arbol[--derecha];
        }
        return suma;
    };
    cout << consultar(entrada[1], salida[1]) << '\n';
    int nodo = cantidad + entrada[3];
    arbol[nodo] = 10;
    while (nodo > 1) {
        nodo /= 2;
        arbol[nodo] = arbol[2 * nodo] + arbol[2 * nodo + 1];
    }
    cout << consultar(entrada[1], salida[1]) << '\n';
}
```

Salida:

```text output
11
17
```

El subárbol de 1 contiene valores 2, 4 y 5. Cambiar el valor del vértice 3 a 10 cambia su suma a 17. El segmento iterativo usa hojas desde `cantidad`; los límites semiabiertos se ajustan tomando los nodos que quedan sueltos antes de subir a los padres.

Construir el orden y el árbol cuesta $O(n)$; actualizar o consultar un subárbol cuesta $O(\log n)$. La DFS mostrada supone profundidad moderada; usa eventos en una pila explícita para cadenas grandes. Un camino arbitrario no siempre es un intervalo Euler: para eso sirve heavy-light decomposition.

## Lazy Propagation

¿Qué pasa si quieres **sumar un valor a todo un rango**? Sin lazy, tendrías que actualizar cada elemento: $O(n)$. Con lazy, es $O(\log n)$.

**Idea:** Cuando actualizas un rango completo de un nodo, no bajes a los hijos de inmediato. Guarda la actualización "pendiente" (lazy) y aplícala cuando sea necesario.

```cpp test
#include <iostream>
using namespace std;

const int MAXN = 200005;
int arr[MAXN];
long long tree[4 * MAXN];
long long lazy[4 * MAXN];

void push(int v, int tl, int tr) {
    if (lazy[v] != 0 && tl != tr) {
        int medio = tl + (tr - tl) / 2;
        tree[2*v] += lazy[v] * (medio - tl + 1);
        lazy[2*v] += lazy[v];
        tree[2*v+1] += lazy[v] * (tr - medio);
        lazy[2*v+1] += lazy[v];
        lazy[v] = 0;
    }
}

void build(int v, int tl, int tr) {
    lazy[v] = 0;
    if (tl == tr) { tree[v] = arr[tl]; return; }
    int tm = (tl + tr) / 2;
    build(2*v, tl, tm);
    build(2*v+1, tm+1, tr);
    tree[v] = tree[2*v] + tree[2*v+1];
}

// Sumar val a todo el rango [l, r]
void rangeUpdate(int v, int tl, int tr, int l, int r, long long val) {
    if (l > tr || r < tl) return;
    if (l <= tl && tr <= r) {
        tree[v] += val * (tr - tl + 1);
        lazy[v] += val;
        return;
    }
    push(v, tl, tr);
    int tm = (tl + tr) / 2;
    rangeUpdate(2*v, tl, tm, l, r, val);
    rangeUpdate(2*v+1, tm+1, tr, l, r, val);
    tree[v] = tree[2*v] + tree[2*v+1];
}

long long query(int v, int tl, int tr, int l, int r) {
    if (l > tr || r < tl) return 0;
    if (l <= tl && tr <= r) return tree[v];
    push(v, tl, tr);
    int tm = (tl + tr) / 2;
    return query(2*v, tl, tm, l, r) +
           query(2*v+1, tm+1, tr, l, r);
}

int main() {
    for (int posicion = 1; posicion <= 4; posicion++) arr[posicion] = posicion;
    build(1, 1, 4);
    rangeUpdate(1, 1, 4, 1, 4, 2);
    cout << query(1, 1, 4, 1, 2) << '\n';
    cout << query(1, 1, 4, 3, 3) << '\n';
    rangeUpdate(1, 1, 4, 2, 3, -1);
    cout << query(1, 1, 4, 1, 4) << '\n';
}
```

Salida:

```text output
7
5
16
```

<Callout type="warning">
  Antes de bajar, `push(v, tl, tr)` debe sumar la etiqueta multiplicada por la
  longitud de **cada hijo**. La etiqueta representa un incremento por elemento,
  no un incremento total del segmento. La guía de [lazy
  propagation](/blog/estructuras-persistentes/lazy-propagation) separa aplicar,
  propagar y reconstruir.
</Callout>

## Resumen de complejidades

| Operación             | Sin Segment Tree | Con Segment Tree     |
| --------------------- | ---------------- | -------------------- |
| Construcción          | —                | $O(n)$               |
| Consulta rango        | $O(n)$           | $O(\log n)$          |
| Actualización puntual | $O(1)$           | $O(\log n)$          |
| Actualización rango   | $O(n)$           | $O(\log n)$ con lazy |

## Ejercicio

Dado un arreglo de N enteros, responde Q operaciones:

- `1 l r`: suma de `[l, r]`
- `2 pos val`: cambiar `arr[pos] = val`

<summary>Ver solución</summary>

```cpp
#include <iostream>
using namespace std;

const int MAXN = 200005;
long long tree[4 * MAXN];
int arr[MAXN], n, q;

void build(int v, int tl, int tr) {
    if (tl == tr) { tree[v] = arr[tl]; return; }
    int tm = (tl + tr) / 2;
    build(2*v, tl, tm);
    build(2*v+1, tm+1, tr);
    tree[v] = tree[2*v] + tree[2*v+1];
}

long long query(int v, int tl, int tr, int l, int r) {
    if (l > tr || r < tl) return 0;
    if (l <= tl && tr <= r) return tree[v];
    int tm = (tl + tr) / 2;
    return query(2*v, tl, tm, l, r) + query(2*v+1, tm+1, tr, l, r);
}

void update(int v, int tl, int tr, int pos, int val) {
    if (tl == tr) { tree[v] = val; return; }
    int tm = (tl + tr) / 2;
    if (pos <= tm) update(2*v, tl, tm, pos, val);
    else update(2*v+1, tm+1, tr, pos, val);
    tree[v] = tree[2*v] + tree[2*v+1];
}

int main() {
    cin >> n >> q;
    for (int i = 1; i <= n; i++) cin >> arr[i];
    build(1, 1, n);

    while (q--) {
        int t;
        cin >> t;
        if (t == 1) {
            int l, r;
            cin >> l >> r;
            cout << query(1, 1, n, l, r) << "\n";
        } else {
            int pos, val;
            cin >> pos >> val;
            update(1, 1, n, pos, val);
        }
    }
    return 0;
}
```
