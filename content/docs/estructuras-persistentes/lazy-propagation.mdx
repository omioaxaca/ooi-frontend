## Antes de empezar

Repasa [segment tree](/blog/estructuras-avanzadas/segment-tree). Ahora una actualización suma un valor a **todo un intervalo**, no solo a una posición. Actualizar cada hoja por separado perdería eficiencia.

Aunque el temario agrupa este tema con estructuras persistentes, **lazy propagation no implica persistencia**. El árbol de esta guía es mutable: no conserva versiones antiguas. Lazy aplaza trabajo; persistencia conserva historia.

## Qué significa una etiqueta pendiente

Cada nodo guarda la suma actual de su segmento y una cantidad pendiente de pasar a sus hijos. Si agregamos `delta` a un segmento de longitud `longitud`, su suma aumenta `delta * longitud` y su etiqueta aumenta `delta`.

La suma del nodo ya incluye la actualización. Sus hijos pueden no incluirla todavía. Antes de descender a una parte del segmento, empujamos la etiqueta a ambos hijos y la limpiamos en el padre.

## Tres operaciones bien separadas

**Aplicar** cambia la suma y la etiqueta de un nodo. **Propagar** aplica la etiqueta a los hijos. **Reconstruir** vuelve a sumar los hijos después de una actualización parcial. Confundir estos pasos suele duplicar actualizaciones o perderlas.

Sobre `[1,2,3,4]`, sumar 2 a `[1,4)` produce `[1,4,5,6]`. La suma total pasa de 10 a 16 y la de `[1,3)` es 9.

## C++17

Todos los intervalos son semiabiertos e indexados desde cero. El árbol se construye con un arreglo no vacío; los intervalos consultados o actualizados sí pueden estar vacíos.

```cpp test
#include <iostream>
#include <vector>
using namespace std;

struct SegmentTree {
    int cantidad;
    vector<long long> suma, pendiente;
    SegmentTree(const vector<long long>& valores) : cantidad(static_cast<int>(valores.size())), suma(4 * cantidad, 0), pendiente(4 * cantidad, 0) {
        construir(1, 0, cantidad, valores);
    }
    void construir(int nodo, int inicio, int fin, const vector<long long>& valores) {
        if (fin - inicio == 1) { suma[nodo] = valores[inicio]; return; }
        int medio = inicio + (fin - inicio) / 2;
        construir(2 * nodo, inicio, medio, valores);
        construir(2 * nodo + 1, medio, fin, valores);
        suma[nodo] = suma[2 * nodo] + suma[2 * nodo + 1];
    }
    void aplicar(int nodo, int inicio, int fin, long long delta) {
        suma[nodo] += delta * (fin - inicio);
        pendiente[nodo] += delta;
    }
    void propagar(int nodo, int inicio, int fin) {
        if (pendiente[nodo] == 0 || fin - inicio == 1) return;
        int medio = inicio + (fin - inicio) / 2;
        aplicar(2 * nodo, inicio, medio, pendiente[nodo]);
        aplicar(2 * nodo + 1, medio, fin, pendiente[nodo]);
        pendiente[nodo] = 0;
    }
    void agregar(int izquierda, int derecha, long long delta, int nodo, int inicio, int fin) {
        if (fin <= izquierda || derecha <= inicio) return;
        if (izquierda <= inicio && fin <= derecha) { aplicar(nodo, inicio, fin, delta); return; }
        propagar(nodo, inicio, fin);
        int medio = inicio + (fin - inicio) / 2;
        agregar(izquierda, derecha, delta, 2 * nodo, inicio, medio);
        agregar(izquierda, derecha, delta, 2 * nodo + 1, medio, fin);
        suma[nodo] = suma[2 * nodo] + suma[2 * nodo + 1];
    }
    long long consultar(int izquierda, int derecha, int nodo, int inicio, int fin) {
        if (fin <= izquierda || derecha <= inicio) return 0;
        if (izquierda <= inicio && fin <= derecha) return suma[nodo];
        propagar(nodo, inicio, fin);
        int medio = inicio + (fin - inicio) / 2;
        return consultar(izquierda, derecha, 2 * nodo, inicio, medio)
             + consultar(izquierda, derecha, 2 * nodo + 1, medio, fin);
    }
    void agregar(int izquierda, int derecha, long long delta) { agregar(izquierda, derecha, delta, 1, 0, cantidad); }
    long long consultar(int izquierda, int derecha) { return consultar(izquierda, derecha, 1, 0, cantidad); }
};

int main() {
    SegmentTree arbol({1, 2, 3, 4});
    cout << arbol.consultar(0, 4) << '\n';
    arbol.agregar(1, 4, 2);
    cout << arbol.consultar(0, 4) << '\n';
    cout << arbol.consultar(1, 3) << '\n';
}
```

Salida:

```text output
10
16
9
```

## Coste y composición

Construir cuesta $O(n)$; cada operación de intervalo cuesta $O(\log n)$ y el almacenamiento es $O(n)$. Las sumas, productos por longitud y etiquetas acumuladas deben caber en `long long`.

Dos adiciones pendientes se componen sumándolas. Si agregas **asignación** de rangos, la composición cambia: asignar borra el efecto anterior y luego sumar modifica la asignación. Necesitas distinguir «no hay asignación pendiente» de «asignar cero».

Para combinar lazy con persistencia debes copiar también los nodos que modificas al propagar. Mutar hijos compartidos corrompería versiones antiguas.
