## Antes de empezar

Repasa arreglos, ordenamiento y sumas de intervalos. Dos punteros no significa solamente tener dos índices: la ventaja aparece cuando puedes justificar que cada uno avanza sin regresar.

## Pares con una suma dada

En un arreglo ordenado, coloca un índice en cada extremo y suma sus valores:

1. Si la suma coincide con el objetivo, encontraste dos posiciones distintas.
2. Si es demasiado pequeña, el valor izquierdo no puede formar una respuesta con ninguno de los valores restantes a su derecha: incluso el mayor quedó corto. Descártalo.
3. Si es demasiado grande, descarta el derecho mediante el argumento simétrico.

La condición del ciclo es `izquierda < derecha`, no `<=`: no puedes usar dos veces la misma posición. Los valores sí pueden ser iguales si vienen de posiciones diferentes. Ordenar cambia los índices originales; conserva pares valor-índice si debes reportarlos.

## Ventana deslizante para un subarreglo

Busquemos el segmento más largo cuya suma sea como máximo un límite **no negativo**, con elementos **no negativos**. Extendemos la ventana por la derecha. Mientras la suma exceda el límite, retiramos elementos por la izquierda.

Al terminar ese ajuste, la ventana es válida. Con `[1, 2, 1, 1, 3]` y límite 4, las mejores longitudes van siendo `1, 2, 3, 3, 3`. No ordenamos este arreglo: hacerlo cambiaría sus subarreglos.

Los no negativos son esenciales. Con `[5, -4]` y límite 1, descartar el 5 inmediatamente perdería el segmento completo, cuya suma es 1. Para valores negativos necesitas otro argumento o herramientas basadas en prefijos.

## C++17

El programa responde si existe un par con suma igual al límite y cuál es la mayor longitud de un segmento con suma a lo sumo ese límite. La entrada cumple las condiciones anteriores.

```cpp test
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int cantidad;
    long long limite;
    cin >> cantidad >> limite;
    vector<int> valores(cantidad);
    for (int& valor : valores) cin >> valor;
    vector<int> ordenados = valores;
    sort(ordenados.begin(), ordenados.end());
    int izquierda = 0, derecha = cantidad - 1;
    bool existe = false;
    while (izquierda < derecha) {
        long long suma = 1LL * ordenados[izquierda] + ordenados[derecha];
        if (suma == limite) { existe = true; break; }
        if (suma < limite) izquierda++;
        else derecha--;
    }
    izquierda = 0;
    long long suma = 0;
    int mejor = 0;
    for (derecha = 0; derecha < cantidad; derecha++) {
        suma += valores[derecha];
        while (izquierda <= derecha && suma > limite) suma -= valores[izquierda++];
        mejor = max(mejor, derecha - izquierda + 1);
    }
    cout << (existe ? "SI" : "NO") << '\n' << mejor << '\n';
}
```

Entrada:

```text input
5 4
1 2 1 1 3
```

Salida:

```text output
SI
3
```

## Coste y casos borde

La búsqueda del par cuesta $O(n)$ después de ordenar; ordenar cuesta $O(n\log n)$. La ventana es $O(n)$ aunque tenga un `while` dentro del `for`: cada elemento entra una vez y sale como máximo una vez. La copia para ordenar usa $O(n)$ memoria; la ventana sola usa $O(1)$ adicional.

Prueba arreglo vacío, un elemento, ceros, todos mayores que el límite y una respuesta que toque el último elemento. Para contar subarreglos válidos con estos mismos supuestos, cada extremo derecho aporta `derecha - izquierda + 1`, no solamente uno.

## Practica

¿Cuántos subarreglos de `[1, 1, 1]` tienen suma a lo sumo 2?

<details>
<summary>Respuesta</summary>

Cinco: tres de longitud 1 y dos de longitud 2. Las aportaciones por extremo derecho son 1, 2 y 2. Usa `long long` para el conteo: en un arreglo de tamaño $n$ puede haber $n(n+1)/2$ subarreglos.

</details>
