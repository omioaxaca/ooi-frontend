## Antes de empezar

Necesitas padres, profundidades, tamaños de subárbol y [Fenwick](/blog/estructuras-avanzadas/fenwick-tree). Queremos actualizar el valor de un vértice y consultar la suma de valores en el camino entre dos vértices.

## Hijos pesados y ligeros

Cada vértice elige como **pesado** al hijo con mayor subárbol. Los demás enlaces a hijos son ligeros. Seguir enlaces pesados forma cadenas, y numeramos cada cadena consecutivamente en un arreglo.

Al bajar por un enlace ligero, el tamaño del subárbol se reduce al menos a la mitad: si ese hijo tuviera más de la mitad, sería necesariamente el mayor. Por eso cualquier camino desde la raíz cruza $O(\log n)$ enlaces ligeros.

## Consultar un camino

Mientras los extremos estén en cadenas distintas, procesa la cadena cuyo encabezado tenga mayor profundidad. Suma desde su encabezado hasta su extremo y sube al padre del encabezado. Cuando ambos estén en la misma cadena, suma el intervalo entre ellos.

Cada tramo se procesa una vez. El último intervalo incluye el LCA exactamente una vez. Si guardas pesos de **aristas** en el hijo más profundo, debes excluir el LCA de ese último tramo.

## C++17: valores en vértices

`Q origen destino` consulta un camino. `U vertice valor` reemplaza un valor. El árbol es no vacío, no dirigido y usa índices desde cero. La construcción es iterativa, también para árboles que sean cadenas.

```cpp test
#include <algorithm>
#include <iostream>
#include <stack>
#include <utility>
#include <vector>
using namespace std;

struct Fenwick {
    vector<long long> arbol;
    Fenwick(int cantidad) : arbol(cantidad + 1, 0) {}
    void agregar(int posicion, long long valor) {
        for (int indice = posicion + 1; indice < static_cast<int>(arbol.size()); indice += indice & -indice) arbol[indice] += valor;
    }
    long long prefijo(int fin) const {
        long long suma = 0;
        for (int indice = fin; indice > 0; indice -= indice & -indice) suma += arbol[indice];
        return suma;
    }
    long long rango(int inicio, int fin) const { return prefijo(fin) - prefijo(inicio); }
};

int main() {
    int cantidad, operaciones;
    cin >> cantidad >> operaciones;
    vector<long long> valor(cantidad);
    for (long long& dato : valor) cin >> dato;
    vector<vector<int>> vecinos(cantidad);
    for (int indice = 1; indice < cantidad; indice++) {
        int origen, destino;
        cin >> origen >> destino;
        vecinos[origen].push_back(destino);
        vecinos[destino].push_back(origen);
    }
    vector<int> padre(cantidad, -1), profundidad(cantidad, 0), tamano(cantidad, 1), pesado(cantidad, -1), orden = {0};
    for (int indice = 0; indice < cantidad; indice++) {
        int actual = orden[indice];
        for (int vecino : vecinos[actual]) {
            if (vecino == padre[actual]) continue;
            padre[vecino] = actual;
            profundidad[vecino] = profundidad[actual] + 1;
            orden.push_back(vecino);
        }
    }
    for (int indice = cantidad - 1; indice > 0; indice--) {
        int actual = orden[indice], superior = padre[actual];
        tamano[superior] += tamano[actual];
        if (pesado[superior] == -1 || tamano[actual] > tamano[pesado[superior]]) pesado[superior] = actual;
    }
    vector<int> cabeza(cantidad), posicion(cantidad);
    stack<pair<int, int>> pendientes;
    pendientes.push({0, 0});
    int reloj = 0;
    while (!pendientes.empty()) {
        auto [inicio, encabezado] = pendientes.top();
        pendientes.pop();
        for (int actual = inicio; actual != -1; actual = pesado[actual]) {
            cabeza[actual] = encabezado;
            posicion[actual] = reloj++;
            for (int vecino : vecinos[actual]) {
                if (vecino != padre[actual] && vecino != pesado[actual]) pendientes.push({vecino, vecino});
            }
        }
    }
    Fenwick datos(cantidad);
    for (int actual = 0; actual < cantidad; actual++) datos.agregar(posicion[actual], valor[actual]);
    auto consultar = [&](int primero, int segundo) {
        long long respuesta = 0;
        while (cabeza[primero] != cabeza[segundo]) {
            if (profundidad[cabeza[primero]] < profundidad[cabeza[segundo]]) swap(primero, segundo);
            respuesta += datos.rango(posicion[cabeza[primero]], posicion[primero] + 1);
            primero = padre[cabeza[primero]];
        }
        if (posicion[primero] > posicion[segundo]) swap(primero, segundo);
        return respuesta + datos.rango(posicion[primero], posicion[segundo] + 1);
    };
    while (operaciones--) {
        char tipo;
        int primero;
        long long segundo;
        cin >> tipo >> primero >> segundo;
        if (tipo == 'Q') cout << consultar(primero, static_cast<int>(segundo)) << '\n';
        else {
            datos.agregar(posicion[primero], segundo - valor[primero]);
            valor[primero] = segundo;
        }
    }
}
```

Entrada:

```text input
5 3
1 2 3 4 5
0 1
0 2
1 3
1 4
Q 3 2
U 1 10
Q 3 4
```

Salida:

```text output
10
19
```

## Coste y límites

Descomponer cuesta $O(n)$; inicializar este Fenwick mediante inserciones cuesta $O(n\log n)$. Una actualización puntual cuesta $O(\log n)$ y una consulta de camino $O(\log^2 n)$: hay $O(\log n)$ tramos. La memoria es $O(n)$.

Si la operación no es conmutativa, como concatenar strings o multiplicar matrices, debes conservar la dirección de los tramos. Si cambian las aristas, esta descomposición estática deja de representar el árbol.
