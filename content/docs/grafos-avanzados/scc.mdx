## ¿Qué es una SCC?

En un grafo **dirigido**, una **Componente Fuertemente Conexa** (Strongly Connected Component) es un grupo máximo de nodos donde puedes llegar de cualquiera a cualquier otro **siguiendo la dirección** de las aristas.

**Analogía:** En una ciudad con calles de un solo sentido, una SCC es una zona donde puedes ir de cualquier esquina a cualquier otra (quizás dando vueltas).

## Algoritmo de Kosaraju

Dos pasadas de DFS:

```cpp
#include <iostream>
#include <vector>
#include <stack>
using namespace std;

const int MAXN = 100005;
vector<int> adj[MAXN], radj[MAXN];  // Grafo y grafo transpuesto
bool vis[MAXN];
int comp[MAXN];
stack<int> orden;

void dfs1(int u) {
    vis[u] = true;
    for (int v : adj[u]) {
        if (!vis[v]) dfs1(v);
    }
    orden.push(u);  // Postorden
}

void dfs2(int u, int id) {
    vis[u] = true;
    comp[u] = id;
    for (int v : radj[u]) {
        if (!vis[v]) dfs2(v, id);
    }
}

int main() {
    int n, m;
    cin >> n >> m;

    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        radj[v].push_back(u);  // Grafo transpuesto
    }

    // Paso 1: DFS en el grafo original
    fill(vis, vis + n + 1, false);
    for (int i = 1; i <= n; i++) {
        if (!vis[i]) dfs1(i);
    }

    // Paso 2: DFS en el grafo transpuesto, en orden inverso de finalización
    fill(vis, vis + n + 1, false);
    int numSCC = 0;
    while (!orden.empty()) {
        int u = orden.top(); orden.pop();
        if (!vis[u]) {
            numSCC++;
            dfs2(u, numSCC);
        }
    }

    cout << "SCCs: " << numSCC << endl;
    for (int i = 1; i <= n; i++) {
        cout << "Nodo " << i << " → SCC " << comp[i] << endl;
    }

    return 0;
}
```

**Complejidad:** $O(V + E)$

### ¿Por qué funciona?

1. El primer DFS ordena los nodos por tiempo de finalización.
2. Procesar en orden inverso en el grafo transpuesto asegura que cada DFS solo alcanza nodos de la misma SCC.

## Tarjan: una DFS y una pila de componentes pendientes

Tarjan no necesita el grafo invertido. Guarda un tiempo de entrada, un valor `bajo` y una pila de vértices que todavía no han sido asignados a una SCC.

Después de explorar un hijo, incorpora su `bajo`. Para una arista hacia un vértice ya visitado, incorpora su tiempo de entrada **solo si sigue en la pila**. Una arista hacia una SCC ya cerrada no debe unirla con la actual.

Cuando `bajo[actual] == entrada[actual]`, encontramos la raíz de una SCC: retiramos de la pila hasta llegar a ese vértice. La pila de Tarjan no es la pila de llamadas; un vértice puede terminar su llamada y seguir pendiente de componente.

```cpp test
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

vector<vector<int>> grafo;
vector<int> entrada, bajo, componente, pila;
vector<bool> enPila;
int reloj = 0, grupos = 0;

void tarjan(int actual) {
    entrada[actual] = bajo[actual] = reloj++;
    pila.push_back(actual);
    enPila[actual] = true;
    for (int vecino : grafo[actual]) {
        if (entrada[vecino] == -1) {
            tarjan(vecino);
            bajo[actual] = min(bajo[actual], bajo[vecino]);
        } else if (enPila[vecino]) bajo[actual] = min(bajo[actual], entrada[vecino]);
    }
    if (bajo[actual] == entrada[actual]) {
        while (true) {
            int ultimo = pila.back(); pila.pop_back();
            enPila[ultimo] = false;
            componente[ultimo] = grupos;
            if (ultimo == actual) break;
        }
        grupos++;
    }
}

int main() {
    int vertices, aristas;
    cin >> vertices >> aristas;
    grafo.resize(vertices);
    entrada.assign(vertices, -1);
    bajo.resize(vertices);
    componente.resize(vertices);
    enPila.assign(vertices, false);
    for (int indice = 0; indice < aristas; indice++) {
        int origen, destino;
        cin >> origen >> destino;
        grafo[origen].push_back(destino);
    }
    for (int actual = 0; actual < vertices; actual++) if (entrada[actual] == -1) tarjan(actual);
    cout << grupos << '\n';
    for (int actual = 0; actual < vertices; actual++) {
        if (actual > 0) cout << ' ';
        cout << componente[actual];
    }
    cout << '\n';
}
```

Entrada:

```text input
5 6
0 1
1 0
1 2
2 3
3 2
3 4
```

Salida:

```text output
3
2 2 1 1 0
```

Las SCC son `{0,1}`, `{2,3}` y `{4}`. Sus números pueden ser distintos en Kosaraju y Tarjan: compara particiones, no IDs literales. Ambos algoritmos cuestan $O(V+E)$ tiempo y memoria; sus versiones recursivas requieren cuidado con caminos de profundidad lineal.

**Practica:** agrega `4 -> 0`. Todos los vértices pasan a ser mutuamente alcanzables y debe quedar una sola SCC. Una arista de ida entre dos grupos no basta para fusionarlos: hace falta también un camino de regreso.

## Grafo de condensación (DAG de SCCs)

Después de encontrar las SCCs, puedes "contraer" cada SCC en un solo nodo, creando un DAG:

```cpp
// Después de Kosaraju
set<pair<int,int>> aristasDAG;

for (int u = 1; u <= n; u++) {
    for (int v : adj[u]) {
        if (comp[u] != comp[v]) {
            aristasDAG.insert({comp[u], comp[v]});
        }
    }
}
```

Este DAG es útil para aplicar ordenamiento topológico, DP en grafos, etc.
