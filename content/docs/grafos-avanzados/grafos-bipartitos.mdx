## Coloración general

Una coloración de vértices asigna un color a cada vértice de modo que los extremos de toda arista tengan colores distintos. No es lo mismo encontrar **alguna** coloración que minimizar el número de colores.

Para un grafo simple, una estrategia voraz visita vértices en un orden fijo y elige el primer color que no usan sus vecinos ya coloreados. Siempre obtiene una coloración válida, pero puede usar más colores que el óptimo. Con grado máximo $\Delta$, usa como máximo $\Delta+1$ colores.

```cpp test
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<vector<int>> vecinos = {{1, 2}, {0, 2}, {0, 1}};
    int cantidad = static_cast<int>(vecinos.size());
    vector<int> color(cantidad, -1), prohibido(cantidad, -1);
    for (int actual = 0; actual < cantidad; actual++) {
        for (int vecino : vecinos[actual]) {
            if (color[vecino] != -1) prohibido[color[vecino]] = actual;
        }
        int elegido = 0;
        while (prohibido[elegido] == actual) elegido++;
        color[actual] = elegido;
    }
    for (int elegido : color) cout << elegido << '\n';
}
```

Salida para un triángulo:

```text output
0
1
2
```

Las marcas guardan el vértice actual para evitar limpiar un vector completo en cada paso. Cada color descartado corresponde a algún vecino coloreado: el tiempo total es $O(n+m)$ y el espacio adicional $O(n)$. El código supone que no hay lazos; un vértice unido consigo mismo no admite una coloración propia.

Encontrar el número cromático mínimo en grafos generales es un problema difícil, NP-hard. Para **dos colores**, en cambio, BFS o DFS permite decidir en tiempo lineal: ese es el caso bipartito.

## ¿Qué es un grafo bipartito?

Un grafo es **bipartito** si puedes dividir sus nodos en dos grupos (A y B) de modo que todas las aristas van de un grupo al otro (nunca dentro del mismo grupo).

**Ejemplo:** Un grupo contiene tareas y el otro máquinas; una arista indica que una máquina puede realizar una tarea. Todas las aristas cruzan entre grupos.

```
Grupo A: {1, 4, 5}     Grupo B: {2, 3, 6}

1 --- 2
|     |
3 --- 4
|     |
5 --- 6
```

## Verificar si es bipartito: coloración con BFS

Intenta colorear el grafo con 2 colores. Si en algún momento un vecino ya tiene el mismo color, no es bipartito.

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

vector<int> adj[100005];
int color[100005];  // -1 = sin color

bool esBipartito(int inicio) {
    queue<int> q;
    q.push(inicio);
    color[inicio] = 0;

    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u]) {
            if (color[v] == -1) {
                color[v] = 1 - color[u];
                q.push(v);
            } else if (color[v] == color[u]) {
                return false;
            }
        }
    }
    return true;
}

int main() {
    int n, m;
    cin >> n >> m;

    for (int i = 0; i < m; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    fill(color, color + n + 1, -1);

    bool bipartito = true;
    for (int i = 1; i <= n; i++) {
        if (color[i] == -1) {
            if (!esBipartito(i)) {
                bipartito = false;
                break;
            }
        }
    }

    cout << (bipartito ? "Es bipartito" : "No es bipartito") << endl;
    return 0;
}
```

**Propiedad:** Un grafo es bipartito si y solo si **no tiene ciclos de longitud impar**.

Un recorrido alterna colores en cada arista. Un ciclo impar exigiría que el vértice inicial tuviera el color contrario al regresar, una contradicción. Revisa todas las componentes, no solamente la que contiene al primer vértice. Un triángulo no es bipartito y necesita tres colores; un ciclo de cuatro vértices sí admite dos. El BFS cuesta $O(n+m)$ tiempo y $O(n)$ espacio adicional.

## Ejercicio de práctica

Dado un grafo, determina si es bipartito. Si sí, imprime los dos grupos.

<summary>Ver solución</summary>

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

vector<int> adj[100005];
int color[100005];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    fill(color, color + n + 1, -1);
    bool ok = true;

    for (int i = 1; i <= n && ok; i++) {
        if (color[i] != -1) continue;
        queue<int> q;
        q.push(i);
        color[i] = 0;
        while (!q.empty() && ok) {
            int u = q.front(); q.pop();
            for (int v : adj[u]) {
                if (color[v] == -1) {
                    color[v] = 1 - color[u];
                    q.push(v);
                } else if (color[v] == color[u]) {
                    ok = false;
                }
            }
        }
    }

    if (!ok) {
        cout << "No es bipartito" << endl;
    } else {
        cout << "Grupo 0: ";
        for (int i = 1; i <= n; i++) if (color[i] == 0) cout << i << " ";
        cout << endl << "Grupo 1: ";
        for (int i = 1; i <= n; i++) if (color[i] == 1) cout << i << " ";
        cout << endl;
    }
    return 0;
}
```
